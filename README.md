# Feedly

Feedly 是一款轻量、私密的跨平台 RSS 阅读器。它在本地订阅和阅读你的资讯源，不上传任何数据，界面简洁、支持快捷键，长时间阅读也不累眼。

> 想参与开发或了解实现，请看 [AGENTS.md](AGENTS.md) 与 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。本文件只讲怎么用。

## 主要功能

- **订阅管理**：添加 RSS / Atom 订阅源，用文件夹分类，支持重命名、移动、删除。
- **舒适阅读**：三栏界面（订阅列表 · 文章列表 · 正文），正文以干净的排版呈现；浅色主题采用护眼草绿色背景。
- **离线全文**：后台自动抓取正文全文并把配图缓存到本地，抓到的文章在列表右侧显示绿色标记；抓不到时退回源里的摘要。
- **已读与星标**：点开即标记已读，可收藏星标，也能一键"全部标记已读"。
- **搜索与过滤**：按关键词搜索，并在"全部 / 未读 / 星标"之间切换。
- **自动刷新**：可设置定时自动更新，刷新时显示实时进度；支持"条件请求"，源没有更新时几乎不耗流量。
- **OPML 导入 / 导出**：从其他阅读器一键迁移订阅，也能随时备份导出。
- **深色模式**：跟随系统 / 浅色 / 深色三种主题。

## 开始使用

### 添加第一个订阅

1. 点击左侧栏顶部的 **＋**（或按 `c`）。
2. 粘贴订阅地址（Feed URL），例如 `https://example.com/feed.xml`。
3. 名称可留空——Feedly 会自动读取源里的标题。点"保存"即可。

想先做分类，可点工具栏上的文件夹图标新建文件夹，再通过某个订阅右侧的 ⋮ 菜单选择「重命名/移动」把它归入对应文件夹。

### 阅读

- 左栏选择某个订阅或文件夹（或"全部文章"）来限定范围。
- 中栏点击文章即可阅读，未读文章前有蓝点。
- 点文章右侧的 ☆ 可**星标**收藏。
- 正文顶部的 ↗ 按钮会在应用内打开原文页（卡片形式，顶部显示域名）；点标题栏的返回箭头回到正文。
- 正文里的网址（例如"原文链接：https://…"）也可直接点击，同样在应用内打开；其它外部链接仍交给系统浏览器。
- 文章列表滚动到底会自动加载更多。

### 搜索与过滤

- 顶部搜索框输入关键词，可搜索标题与正文。
- 用顶部的 **全部 / 未读 / 星标** 切换筛选状态。

### 全部标记已读

点击顶部的 ✓ 按钮（或按 `m`），会把当前订阅 / 文件夹（或全部）里的未读一键清空。

### 导入 / 导出订阅（OPML）

- **导入**：顶部"导入" → 选择 `.opml` 文件，或直接粘贴内容 → 点"导入"。已存在的订阅会自动跳过。
- **导出**：顶部"导出" → 复制或下载 `.opml` 文件，用于备份或迁移到其他阅读器。

### 设置

点顶部齿轮（或按 `,`）打开设置：

- **自动刷新间隔**：手动 / 5 分钟 … 24 小时。
- **主题**：跟随系统 / 浅色 / 深色。

## 键盘快捷键

| 按键 | 作用 |
| --- | --- |
| `j` / `↓` | 下一篇 |
| `k` / `↑` | 上一篇 |
| `n` / `p` | 下一个 / 上一个有未读的订阅 |
| `Enter` | 在浏览器打开原文 |
| `s` | 星标 / 取消星标 |
| `u` | 切换当前文章已读 / 未读 |
| `m` | 当前范围全部标记已读 |
| `r` | 刷新全部订阅 |
| `/` | 聚焦搜索框 |
| `c` | 新建订阅 |
| `,` | 打开设置 |
| `?` | 显示 / 隐藏快捷键帮助 |
| `Esc` | 关闭弹窗 / 清除选择 |

## 数据存放与隐私

- 所有订阅、文章和设置都保存在**本机**的 SQLite 数据库中，不会上传到任何服务器。
- 正文配图缓存在应用数据目录的 `images/` 下，删掉不影响订阅数据，下次打开会重新下载。
- 应用完全离线也能阅读已抓取的内容；联网仅用于抓取你订阅的公开源。
- 数据库位置（应用数据目录 `feedly.db`）：
  - **macOS**：`~/Library/Application Support/com.feedly.desktop/`
  - **Windows**：`%APPDATA%\com.feedly.desktop\`
  - **Linux**：`~/.local/share/com.feedly.desktop/`
- 想彻底清除数据，退出应用后删除上述目录中的 `feedly.db` 即可。

## 系统要求

Feedly 支持 macOS、Windows 和 Linux。使用网页版内核（系统自带），无需额外安装浏览器。

## 从源码构建（可选）

如果你想在本地自行编译：

```bash
pnpm install
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包安装包，产物在 src-tauri/target/release/bundle/
```

需要先安装 Rust、Node.js 与 pnpm；各平台的 WebView 依赖详见 [AGENTS.md](AGENTS.md)。
